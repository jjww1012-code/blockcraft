# Spielehalle

Browser-Spiele zum gemeinsamen Spielen, auch auf dem iPad.

- `index.html` – Startseite, liest die Spieleliste aus `games.json`
- `blockcraft/` – BlockCraft (Bau-Updates für Welten liegen in `blockcraft/patches/`)
- `vier-gewinnt/` – Vier gewinnt (online mit Raum-Code)

Neues Spiel: eigenen Ordner anlegen und einen Eintrag in `games.json` ergänzen.
